# Fans Rails App Setup

This document captures the initial setup steps and commands for the `fans` Rails 8.0.2 application with Tailwind CSS and Hotwire (Turbo + Stimulus), running inside Docker.

## 1. Directory Structure

```bash
mkdir fans
cd fans
mkdir codex-output
```  
All output and setup notes are stored under `codex-output/20250528090000_initial_setup.md`.

## 2. Dockerfile

Create a `Dockerfile` in the project root:
```Dockerfile
FROM ruby:3.2

# Install system dependencies for SQLite and build
RUN apt-get update -qq \
    && apt-get install -y build-essential libsqlite3-dev nodejs \
    && rm -rf /var/lib/apt/lists/*

WORKDIR /app

# Copy Gemfiles and install gems
COPY Gemfile Gemfile.lock ./
RUN bundle install

# Copy the rest of the application
COPY . .

# Default command
CMD ["bash", "-lc", "bundle exec rails server -b 0.0.0.0"]
```

## 3. .dockerignore

Create `.dockerignore`:
```
/.git
/log
/tmp
*.log
```

## 4. docker-compose.yml

```yaml
version: '3.8'
services:
  web:
    build: .
    command: bash -lc "bundle exec rails server -b 0.0.0.0"
    ports:
      - "3000:3000"
    volumes:
      - .:/app
    environment:
      RAILS_ENV: development
```

## 5. Gemfile

Create or update `Gemfile`:
```ruby
source 'https://rubygems.org'

gem 'rails', '8.0.2'
gem 'puma'
gem 'sqlite3', '~> 1.4'
gem 'hotwire-rails'
gem 'tailwindcss-rails'

# Development & test
group :development, :test do
  gem 'byebug'
end
```

Generate `Gemfile.lock` with:
```bash
docker-compose run --rm web bundle lock --add-platform ruby x86_64-linux
```

## 6. Install Tailwind CSS & Hotwire

```bash
# Install Tailwind CSS
docker-compose run --rm web rails tailwindcss:install

# Install Hotwire (Turbo + Stimulus)
docker-compose run --rm web rails turbo:install stimulus:install
```

## 7. Home Controller & Root Route

```bash
docker-compose run --rm web rails generate controller Home index --skip-assets --skip-helper --no-test-framework
```  
In `config/routes.rb`, set:
```ruby
root 'home#index'
```

## 8. Shared Partials (Nav & Footer)

Create `app/views/shared/_nav.html.erb`:
```erb
<nav class="bg-gray-800 p-4 text-white">
  <div class="container mx-auto">
    <%= link_to 'Fans', root_path, class: 'font-bold' %>
  </div>
</nav>
```

Create `app/views/shared/_footer.html.erb`:
```erb
<footer class="bg-gray-200 p-4">
  <div class="container mx-auto text-center">
    &copy; <%= Time.current.year %> Fans
  </div>
</footer>
```

## 9. Update Application Layout

In `app/views/layouts/application.html.erb`, modify the `<body>` to:
```erb
<body>
  <%= render 'shared/nav' %>
  <%= yield %>
  <%= render 'shared/footer' %>
</body>
```

## 10. Build & Run

```bash
docker-compose build
docker-compose up
```

Visit http://localhost:3000 to see the home page with Tailwind styling and Hotwire ready for real-time interactivity.
